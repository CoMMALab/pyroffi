# Where the nonparametric path (§3) does not follow from the parametric one (§2)

Companion to `THEORY_IDENTIFIABLE_REFIT.md`. That document derives a
three-stage procedure — **fit wide → eigendecompose the cost-gradient Gram →
refit on the identifiable subspace** — and states it twice: once for a known
cost library (§2, "Path A") and once for an unknown cost in an RKHS (§3,
"Path B"). §3 is written by transcribing §2 with `θ → w` and asserting the
structure is "identical".

It is not identical. This document records **one implementation bug** and
**four places where the substitution silently breaks something that was
load-bearing in the finite named-basis case**, together with what the
literature says about each. Written 2026-08-28 after measuring a 37× fit-RMSE
gap between the two paths on a shared demonstration.

Measurements referenced here live in `scratch/logs/rkhs_probe.log`,
`scratch/logs/rkhs_screen.log`, and `scratch/logs/study3_samedemo_m64.log`.

---

## 0. The empirical result this explains

One demonstration generated by the named cost, handed to both hypothesis
classes, every other difference aligned (`build_same_demo`):

| | Path A (named, K=9) | Path B (RKHS M=64, K=70) |
|---|---|---|
| init | 0.0505 | 0.4571 |
| wide fit | **0.0065** | **0.2439** |
| refit on `U_r` | 0.0069 (gen 0.0097) | 0.3511 (gen 0.2821) |
| reduction | 7.8× | 1.9× |
| identifiable | r=6/9 | r=30/70 |

37× apart. The gap is ~10× larger than the pipeline's own numerical
instability, so it is a real effect and not a measurement artifact.

## 1. The bug: the feature map dropped the context argument

§3 defines the candidate cost as

    C_w(x, c) = ⟨ w, Φ(x, c) ⟩_H

`Φ` takes the context `c`. The implementation's feature map does not:

```python
q = problem.unpack(x_flat, scene)
u = jnp.concatenate([q[:-1], q[1:] - q[:-1]], axis=-1)   # [q_t, Δq_t] only
```

`scene` enters only through `unpack`'s boundary conditions. `obs_center`,
`obs_radius` and the pick/place targets never reach the features, so the
implemented class is `C_w(x)`, not `C_w(x, c)`.

**This alone is sufficient to explain the gap.** Transport's ground-truth
weights are `[0.231 smooth, 0.629 clearance, 0.140 upright]`, and `clearance`
is *defined* by the obstacle (`ioc/robot/problem.py:113`, a `softplus` of a
`softmin` over sphere-to-obstacle distances). A feature map blind to `c`
cannot represent it at any `M` or lengthscale. Per-term held-out R², fitting
each named term from the kernel features alone:

| term | weight | from `[q, Δq]` | with per-link obstacle distances |
|---|---|---|---|
| smooth | 0.231 | 0.976 | 0.951 |
| **clearance** | **0.629** | **0.209** | **0.576** |
| upright | 0.140 | 0.868 | 0.849 |

Restoring `c` lifts total non-negative R² from 0.569 to 0.915 and the gradient
alignment `cos(∇C_true, ∇C_fit)` from 0.257 to 0.865. Gradient alignment is
the operative quantity: the inner solver follows `∇ₓC`, so a cost pointing
~51° away from the truth puts `x*` elsewhere no matter how well the outer loop
optimises.

This is not a novel requirement. GPIRL (Levine, Popović & Koltun, NeurIPS
2011) — the canonical nonlinear-reward IRL method — learns the reward as a
nonlinear function *of hand-designed features* and infers each feature's
relevance; prior IRL used a linear combination of the same features. Nobody
in this line feeds raw state to the kernel. "Nonparametric cost" never meant
"no feature engineering"; it meant "no assumed functional form *over* the
features".

**Fix:** `_rff_residual_fn(mode="geom")` appends per-link distance to
`obs_center`. Generic scene geometry, not the cost term — no margin, no
softplus, no soft-min reduction.

### 1a. A hypothesis the data killed

`Σ_t f(q_t, Δq_t)` is first-order Markov and so cannot express an acceleration
penalty, while `smooth` couples three consecutive waypoints. This looked like
a second structural defect. It is not: `smooth` fits at R² 0.976 from the base
descriptor, and adding second differences moved it to 0.983 — nothing.
Recorded because it is the kind of argument that is persuasive and wrong.

## 2. `C* ∈ H` is assumed; `‖C*‖_H` is what actually matters

§3 assumes `C* ∈ H` and stops there. Because the squared-exponential kernel is
universal, that assumption feels free. It is not — density in the sup norm is
not membership, and more importantly the **finite-`M` approximation error is
governed by the RKHS norm and the problem's effective dimension**, neither of
which §3 mentions.

Rudi & Rosasco (NeurIPS 2017) give optimal learning rates with `M ≪ n` random
features, but `M` is set by the *effective degrees of freedom*, not assumed;
subsequent work (Rudi et al., leverage-score sampling) shows data-dependent
sampling sharply reduces the `M` required versus uniform draws from the
spectral density. `make_rff_residual_fn` samples `Ω ~ N(0, ℓ⁻²I)` uniformly —
plain Rahimi–Recht, the worst case in that analysis.

Worse, `clearance` is the shape random Fourier features handle least well.
The RFF literature is explicit that fine-scale and non-smooth structure lives
in the **tails of the spectral density, which uniform Monte Carlo samples
infrequently**, and that non-smooth targets can drive the required feature
count toward exponential in the input dimension. `clearance` is a near-hinge
in a 14-dimensional (base) or 27-dimensional (geom) descriptor — squarely that
regime. This is why the context fix takes clearance only to 0.576 while the
other two terms sit at 0.95 and 0.85: it goes from *unrepresentable* to merely
*worst*.

**Consequence for the write-up:** the honest claim is not "assume `C* ∈ H`" but
"assume `C*` has bounded RKHS norm at the effective dimension of this problem,
with an approximation term of order `M^{-1/2}` carrying that norm as its
constant." That is a weaker and more careful theorem than §3 currently states.

## 3. "retain the directions with `λ_j > 0`" is vacuous in infinite dimensions

§3 says to keep the eigendirections of `G = Σ_i S_iᵀ S_i` with `λ_j > 0` as the
recovered basis `{ψ_j}`.

In §2 this is well-posed: `K` counts named cost terms, and `r < K` is a real
dichotomy. In §3 `G` is a compact operator on `H`; its spectrum is strictly
positive and accumulates at zero. Every direction has `λ_j > 0`. So `r` is not
a property of the demonstration — it is an artifact of the `M`-truncation plus
a numerical cutoff, and §3 never says which cutoff.

This is not hypothetical. `ioc/identifiability.py::select_rank` defaults to
`rule="gap"` (largest ratio between consecutive eigenvalues), while
`run_procedure` passes `frac=TRACE_FRAC`, which the gap rule **ignores** — and
the log line still prints ">= 95% cumulative trace". The same Path A spectrum
gives `r = 2` under the trace rule and `r = 6` under the gap rule. Ranks in
logs written before that default changed are not comparable to later ones.

**Consequence:** for Path B, any reported `r` must state the truncation `M` and
the cutoff rule, and cannot be interpreted as "the number of identifiable cost
directions" without both.

## 4. The RKHS formulation is incompatible with the solver, and §3 does not reconcile them

`⟨w, Φ⟩_H` is linear in `w` and sign-unconstrained. The inner solver is damped
Gauss-Newton on a nonlinear least-squares problem and requires

    C(x; θ, c) = Σ_k (θ_k / s_k) ‖r_k(x, c)‖²,   θ ⪰ 0

— non-negative, and a sum of squared residuals. A generic element of `H`
is neither. §3 says the structure is "identical to Path A, `θ → w`", but Path
A's structure carries a non-negativity requirement and a squared-residual form
that the substitution silently discards.

The implementation bridges the gap by using `Σ_j w_j φ_j(u)²` with `w` on the
simplex. Via `cos² z = (1 + cos 2z)/2` that class is *non-negative
combinations of doubled-frequency cosines* — a strictly smaller and
differently-shaped space than the RKHS §3 names. The theory and the code are
not describing the same object.

**The principled fix exists.** Marteau-Ferey, Bach & Rudi, *Non-parametric
Models for Non-negative Functions* (NeurIPS 2020, arXiv:2007.03926) model
non-negative functions as **PSD models**

    f(x) = φ(x)ᵀ M φ(x),    M ⪰ 0

prove a representer theorem, give a convex dual, and show the resulting space
is strictly richer than generalized linear models. The current
parametrisation is the **strictly diagonal special case** `M = diag(w), w ⪰ 0`,
which discards every off-diagonal cross-feature term. The containment
`diag(w) ⊂ PSD` is elementary; a *quantified* expressiveness gap is not quoted
here because only the abstract was retrieved — read the paper before relying
on it.

A PSD model is non-negative by construction (so the least-squares solver is
satisfied) while remaining linear in the parameter `M`, which is exactly the
reconciliation §3 needs.

**Not yet implemented, deliberately.** At `M = 256` a full PSD model has
`M(M+1)/2 = 32 896` parameters. Stage 2 eigendecomposes a `K × K` Gram, so
this is computationally infeasible as written and would destroy the
comparability with Path A's `K = 9`. A low-rank factorisation `M = BBᵀ` with
`B ∈ ℝ^{M×q}` is the practical route. Left as future work.

## 5. Recovered "up to what?" — and the one-scene ceiling

§3 says the recoverable object is an `r`-dimensional functional basis `{ψ_j}`.
It does not say up to *what equivalence*. In §2 the answer is clear: the
identifiable subspace of the span of the named terms. In §3, `{ψ_j}` depends
on the kernel; two kernels give different bases both reproducing the demo
equally well. Without an equivalence relation the claim is not falsifiable and
a recovered basis cannot be scored right or wrong. This is the same conclusion
already recorded elsewhere in this project: for the unknown-cost case,
*behaviour* may be the only well-defined target.

The literature is blunter, and its point applies to **both paths**. Cao, Cohen
& Szpruch, *Identifiability in Inverse Reinforcement Learning*
(arXiv:2106.03498), prove the reward is not identifiable even given perfect
knowledge of optimal behaviour, and is recoverable only up to a constant — and
then only given demonstrations under **sufficiently different environments**
(or under two distinct discount factors).

Every result in this study up to 2026-08-28 fit a **single scene**. So an
unknown fraction of the rank deficiency that the entire three-stage refit
exists to manage is an artifact of that choice rather than a property of the
cost. Path A's measured `captured_frac = 0.859` is a one-scene ceiling too.

**Fix:** `_scenes_multi(n_fit, n_gen)` fits several scenes and holds others
out. It jitters `obs_center` as well as `q_start`/`pick`/`place` — the original
A/B pair moved only the latter three and left the obstacle fixed, which is
precisely the direction that makes a clearance cost identifiable. A demo set
that never moves the obstacle cannot distinguish "avoid that obstacle" from
"prefer that region of joint space".

## 6. Summary

| # | Issue | Status |
|---|---|---|
| 1 | Feature map drops `c`; `clearance` unrepresentable | **Fixed** (`mode="geom"`) |
| 2 | `‖C*‖_H` / effective dimension absent from §3; RFF weak on near-hinges | Theory amended above; leverage-score sampling available if `M` binds |
| 3 | `λ_j > 0` vacuous in infinite dimensions; `r` is a truncation artifact | Documented; `select_rank` rule must be reported with every `r` |
| 4 | RKHS form incompatible with the non-negative least-squares solver | Fix identified (PSD models); deferred, `K` explodes |
| 5 | No equivalence class for `{ψ_j}`; single-scene fitting caps identifiability | **Fixed** for the scene half (`_scenes_multi`) |

The defensible version of §3 is: **the §2 procedure does not lift to the
nonparametric case as stated.** It lifts to a *finite-`M` random-feature* case
with an explicit approximation-error term, a stated cone constraint, a declared
rank cutoff, and demonstrations from several distinct environments.
